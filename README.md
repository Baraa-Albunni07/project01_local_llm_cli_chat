# Local LLM CLI Chat

Ein einfaches Python-Skript, um über eine OpenAI-kompatible Schnittstelle mit einem lokal laufenden Sprachmodell im Terminal zu chatten.

## Voraussetzungen
- Python 3.10+
- Ein laufender lokaler Modell-Server (z. B. Ollama, LM Studio oder AMD Lemonade)

## Installation & Start
```bash
pip install -r requirements.txt
python chat.py
